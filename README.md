# meera-kurup.github.io/meera-kurup-website

Personal portfolio site for Meera Kurup — PM II at Microsoft CoreAI.

Built with React 18, TypeScript, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This builds the site and pushes the `dist/` folder to the `gh-pages` branch, which GitHub Pages serves automatically.

After the first deploy, make sure GitHub Pages is configured to serve from the **`gh-pages` branch** under **Settings → Pages**.
